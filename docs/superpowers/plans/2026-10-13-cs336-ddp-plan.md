# CS336 A1 Four-GPU DDP and Batch-Prefetch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Run the existing A1 trainer on physical GPUs 4–7 with per-GPU batch 16, rank-safe logging/checkpointing, and retain CPU/GPU prefetch only if it improves measured throughput.

**Architecture:** Keep single-process training when torchrun is absent. Under torchrun, initialize one DDP process per visible GPU, partition each rank’s start-index range, and restrict side effects to rank 0. Add an optional bounded host-batch prefetcher with pinned memory and asynchronous CUDA transfer, then compare it with the simple loader before enabling it.

**Tech Stack:** Python 3.12, PyTorch 2.11, NumPy, pytest, torchrun/NCCL.

**Spec:** docs/superpowers/specs/2026-10-13-cs336-bpe-ddp-design.md

## Global Constraints

- Physical GPUs are 4–7, selected with CUDA_VISIBLE_DEVICES=4,5,6,7; torchrun local ranks are 0–3.
- Default per-GPU batch is 16 and global batch is 64.
- Rank start-index ranges do not overlap; sampling within each range may use replacement.
- Only rank 0 writes logs and checkpoints; validation cadence is every 1,000 steps, checkpoint cadence every 5,000 steps, plus final save.
- A1 target is 327,680,000 processed tokens; with 4 ranks, per-rank batch 16, and context 256, default num_steps=20,000 reaches the target. WORLD_SIZE=1 preserves single-process CPU/CUDA use; batch 16 then needs 80,000 steps for the same token budget.
- Default cosine_cycle_iters matches num_steps=20,000; evaluation is every 1,000 steps and checkpoints every 5,000 steps.
- Keep prefetch only if three runs show at least 5% median throughput improvement without correctness or memory issues.
- Do not launch long OWT training; use synthetic/mmap token IDs and a short real-code-path smoke test.
- The remote project has no Git metadata; preserve files remotely and publish via the authorized GitHub path only after verifying repository and write access.

## Review Focus

- WORLD_SIZE=1 must not initialize a process group: test_single_process_context_is_noop in Task 1.
- Rank start-index partitions must be deterministic and disjoint: test_get_batch_respects_rank_partition_and_seed in Task 2.
- All ranks must join evaluation reduction in the same order: test_distributed_evaluation_with_valid_data_smoke in Task 3.
- Checkpoints must contain unprefixed model keys and be loadable: test_rank_zero_checkpoint_round_trip in Task 3.
- Prefetch shutdown and producer exceptions must not hang training: test_prefetcher_propagates_worker_error_and_closes in Task 4.
